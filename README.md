Non Following Back Detector is and extension that detects people who doesn't follow you back in your social medias (instagram for now, i'll add tiktok later)  and you can easily unfollow them by one click
how to use:
1-download the zip file
2-open chrome and go to: chrome://extensions/
3-upload the zip file after extracting it
4-pin the extension and go to instagram
5-open the followers list in your page and scroll till the end 
6-click on the pinned extension logo and click (collect followers)
7-repeate the same thing with the following list and then click on (show non following back)
8-a new tab with the list of non following back will open.
